# HeroSection Specification

- Reference: `docs/design-references/homepage-final.png`.
- Desktop two-column composition, 42% copy / 58% particle portrait; minimum 100svh.
- Copy includes small circular portrait, name, role, affiliation, ERC project label, all three existing biography paragraphs, View Research and Email buttons.
- Particle portrait is strict left profile with wide smoked visor, anatomically human ear, high tie, and long ponytail hanging downward.
- Canvas samples only the right subject from `robot-source.png`; background/nav pixels are excluded. Render as hollow triangles with pointer repulsion and spring return.
- Mobile stacks copy then a 74svh visual. Use static image when canvas density would harm performance.
