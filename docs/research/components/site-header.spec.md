# SiteHeader Specification

- Fixed at top, full width, z-index 40; 92px desktop, 72px mobile.
- Logo is an original four-quadrant geometric M mark using ivory, violet, teal, and amber.
- Desktop nav: ABOUT, RESEARCH, PUBLICATIONS, CV, then violet MING MA pill.
- Scrolled state starts after 48px: tinted background, 1px bottom border, compact visual density.
- Mobile: logo, MENU button, full-screen menu with the same anchors. Escape and link click close the menu.
- Active section indicated by color plus a small line; never color alone.
